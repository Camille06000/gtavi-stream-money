# Codes de triche GTA 6 (PS5 et Xbox Series X|S)

État au 18 novembre 2026 : codes annoncés par des guides publiés avant la sortie (GameSpot, Red Bull, Insider Gaming et d'autres). Rockstar n'a pas encore de page officielle des codes. Revérifie chaque code en jeu après la sortie et mets à jour la colonne Statut.

## Comment les entrer

1. Termine l'histoire principale. Les codes se débloquent ensuite, certains demandent une tâche en plus (voir le tableau).
2. Appuie sur Haut de la croix directionnelle pour ouvrir le téléphone en jeu.
3. PS5 : maintiens L1 + R1. Xbox : maintiens LB + RB.
4. Entre la séquence à la croix directionnelle. Les séquences sont les mêmes sur les deux consoles.

**Sauvegarde d'abord.** Utiliser un code bloque la sauvegarde, les trophées et les succès pour le reste de la session.

- « Raise Wanted Level » : aucun code ne porte ce nom. Le code annoncé est Raise Heat Level : ← ↓ → ↓ ↑ ↓ ↑.
